# 📚 Study Planner

A simple web-based Study Planner developed using PHP, HTML, CSS, Bootstrap, and JSON.

The application allows users to create and view study plans by entering the study date, subject, time slot, and notes.

## ✨ Features

- Add new study plans
- Specify study date
- Add subject and time slot
- Add notes for each study session
- View saved study plans
- Store study plans using a JSON file
- Simple and user-friendly interface

## 🛠️ Technologies Used

- **PHP** – Backend development
- **HTML** – Page structure
- **CSS** – Styling
- **Bootstrap** – Responsive user interface
- **JSON** – Data storage
